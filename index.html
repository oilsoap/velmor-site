The problem

An agent fails on step forty of a run nobody watched. By the time you look, the inputs are gone, the model has moved on, and the same run will not fail the same way twice.

01

Record

Every model call, tool call, input and output is captured in order, with timing. Nothing is sampled away.

02

Replay

Open any run and step through it exactly as it happened. Change one step and watch what the agent does next.

03

Regress

Turn a failed run into a test with one action. It runs on every change, so a fixed failure stays fixed.

How it works

Three lines to start recording.

  1. 01Add the SDK to the code that runs your agent.
  2. 02Run it as usual. Every run is recorded as it happens.
  3. 03When a run fails, open it, replay it, and save it as a test.

agent.py · example, replace with your SDK

import velmor

velmor.init(project="[YOUR PROJECT]")

with velmor.record("support-agent"):
    agent.run(task)
